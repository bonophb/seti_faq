# SETI FAQ

SETI 보드게임 FAQ 검색과 외계종 발견 추첨을 제공하는 정적 사이트입니다.
GitHub Pages에서 별도 빌드 없이 실행합니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | FAQ 화면과 스타일 |
| `faq.js` | 시트 데이터 로딩, 검색, 필터, FAQ 공유 링크 |
| `randomizer.html` | 외계종 추첨 화면과 스타일 |
| `randomizer.js` | 제외 설정, 추첨, 진행 상태 저장 |
| `shared.js` | 언어 감지, GA4 초기화·이벤트, 서비스 워커 등록 |
| `sw.js` | 오프라인 리소스 캐시 |
| `manifest.json` | 홈 화면 설치 정보 |

HTML의 `shared.js`는 각 페이지의 JavaScript보다 먼저 로드합니다.
페이지 스크립트는 화면 요소 생성 후 실행되도록 body 끝에 둡니다.
HTML의 버튼에서 전역 함수를 호출하므로 현재는 일반 스크립트를 사용합니다.

## FAQ 데이터 편집

FAQ 데이터는 구글 시트에서 CSV로 읽습니다. 데이터 주소는 `faq.js`에 있습니다.
시트의 `ID` 열은 `seti-0001` 같은 고정 문자열이며 기존 ID를 변경하거나 재사용하지 않습니다.
새 FAQ에는 사용하지 않은 ID를 부여합니다. 현재 초기 데이터는 `seti-0170`까지 사용합니다.
정렬할 때는 ID 열을 포함한 전체 데이터 범위를 함께 정렬합니다.

`faq.js`의 `LEGACY_FAQ_IDS`는 기존 공유 링크의 대응표입니다.
행 순서나 질문을 수정해도 이 대응표를 다시 생성하지 않습니다.

## 변경 확인

- FAQ 검색, 본판·확장 및 카테고리 필터, 언어 전환, 공유 링크를 확인합니다.
- 추첨 모드, 제외 설정, 좌우 중복 방지, 저장된 상태 복원을 확인합니다.
- 새 실행 파일을 추가하면 `sw.js`의 `LOCAL_ASSETS`에도 등록합니다.
- 캐시 대상 파일 구조를 변경할 때 캐시 버전을 올려 새 파일들이 설치되도록 합니다.
