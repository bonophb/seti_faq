# SETI FAQ

SETI 보드게임의 FAQ 검색, 외계종 발견 추첨, 태양계 시뮬레이터를 제공하는 한국어·영어 지원 사이트입니다.

## 주요 기능

### FAQ 검색

- 한국어·영어 질문과 답변을 검색하고, 본판·확장 및 카테고리로 필터링합니다.
- `1`, `#1`, `001`은 질문에 표시된 1번 카드 번호와 정확히 일치하는 FAQ를 찾습니다. 11번이나 100번 카드는 포함하지 않습니다.
- `ET.1`, `et1`, `#ET.1`로 외계종 카드 번호를 검색할 수 있습니다.
- 전각 문자와 연속 공백·줄바꿈을 정규화하고, 여러 검색 단어를 순서와 무관하게 찾습니다.
- 제목과 일치하는 결과를 우선 표시하며, 답변은 화면에 표시되는 텍스트를 기준으로 검색합니다.
- FAQ별 공유 링크, 영어 원문 보기, 공식 룰북 및 외부 FAQ 링크를 제공합니다.

### 외계종 발견 랜더마이저

- 본판 5종 또는 본판과 확장을 합친 8종 중에서 추첨합니다.
- 추첨에서 제외할 외계종을 선택할 수 있으며, 최소 2종은 남겨야 합니다.
- 왼쪽과 오른쪽에 같은 외계종이 중복으로 뽑히지 않습니다.
- 추첨 진행 상태를 저장하여 새로 접속해도 복원합니다.
- 상단 왼쪽에 FAQ 복귀 링크, 그 아래 초기화 버튼, 오른쪽에 언어 선택 버튼이 있습니다.

### 태양계 시뮬레이터

원판 이미지와 중앙 태양을 겹쳐 표시하고, 버튼을 누를 때마다 45°씩 회전합니다.

| 조작 대상 | 함께 회전하는 원판 |
| --- | --- |
| 1번 원판 | 1번 |
| 2번 원판 | 1·2번 |
| 3번 원판 | 1·2·3번 |

- **정방향(반시계)** 및 **역방향(시계)** 버튼을 제공합니다.
- 4번 원판은 고정되며, 중앙 태양은 천천히 반시계 방향으로 자동 회전합니다. 기기의 동작 줄이기 설정에서는 태양 애니메이션을 멈춥니다.
- 원판의 현재 각도는 화면에 표시하지 않습니다.
- 한국어·영어 전환 및 FAQ로 돌아가기 버튼을 제공합니다. 언어를 바꿔도 원판 회전 상태는 유지됩니다.

**사용 전 반드시 함께 게임하는 모든 플레이어의 동의를 구해 주세요.** 다른 플레이어가 시뮬레이터 사용을 치팅 행위로 간주할 수 있습니다. 실제 게임 진행 중 원판은 반드시 반시계 방향으로 회전합니다.

### 공통 편의 기능

- FAQ, 랜더마이저, 시뮬레이터에서 선택한 언어를 공유합니다.
- FAQ와 랜더마이저는 홈 화면 설치 및 캐시를 통한 오프라인 사용을 지원합니다. 최초 로딩과 데이터 갱신에는 인터넷 연결이 필요합니다.

## 파일 구성

GitHub Pages에서 별도 빌드 없이 실행하는 정적 사이트입니다.

| 파일 | 역할 |
| --- | --- |
| `index.html` | FAQ 화면, 탐색 링크와 스타일 |
| `faq.js` | 시트 데이터 로딩, 검색·정렬, 필터, FAQ 공유 링크 |
| `randomizer.html` | 외계종 추첨 화면과 스타일 |
| `randomizer.js` | 제외 설정, 추첨, 진행 상태 저장 |
| `solar-system.html` | 태양계 시뮬레이터 화면, 원판 배치, 태양 애니메이션, GA4 페이지뷰 설정 |
| `solar-system.js` | 원판 회전 제어, 한국어·영어 전환 및 언어 설정 연동 |
| `assets/solar/` | 배경과 외곽 그림자를 정리한 원판·태양 PNG |
| `shared.js` | FAQ·랜더마이저의 언어 감지, GA4 초기화·이벤트, 서비스 워커 등록 |
| `sw.js` | 오프라인 리소스 캐시 |
| `manifest.json` | 홈 화면 설치 정보 |
| `ANALYTICS.md` | FAQ·랜더마이저의 GA4 이벤트 및 설정 안내 |

FAQ·랜더마이저는 `shared.js`를 페이지별 JavaScript보다 먼저 로드합니다.
시뮬레이터는 `solar-system.js`를 `defer`로 실행하며, 같은 언어 저장 키를 사용합니다.

## FAQ 데이터 편집

FAQ 데이터는 구글 시트에서 CSV로 읽습니다. 데이터 주소는 `faq.js`에 있습니다.

- 시트의 `ID` 열은 `seti-0001` 같은 고정 문자열이며, 기존 ID를 변경하거나 재사용하지 않습니다.
- 새 FAQ에는 사용하지 않은 ID를 부여합니다. 초기 데이터는 `seti-0170`까지 부여했으므로, 추가 시에는 시트의 현재 ID 목록을 확인합니다.
- 정렬할 때는 ID 열을 포함한 전체 데이터 범위를 함께 정렬합니다.
- `faq.js`의 `LEGACY_FAQ_IDS`는 기존 공유 링크의 대응표입니다. 행 순서나 질문을 수정해도 이 대응표를 다시 생성하지 않습니다.

## 변경 확인 및 배포

`main` 브랜치 변경은 GitHub Pages 자동 배포로 운영 사이트에 반영됩니다.

- FAQ: 카드 번호 정확 일치, 여러 단어 검색, 검색 순위, 필터, 언어 전환, 공유 링크를 확인합니다.
- 랜더마이저: 모드 선택, 제외 설정, 좌우 중복 방지, 저장 상태 복원 및 초기화를 확인합니다.
- 시뮬레이터: 각 원판의 양방향 45° 회전, 동시 회전 대상, 태양 애니메이션과 언어 전환을 확인합니다.
- 페이지 간 이동과 언어 유지, 모바일 화면에서의 버튼 배치를 확인합니다.
- 오프라인 지원 대상 파일을 추가하면 `sw.js`의 `LOCAL_ASSETS`에도 등록합니다.
- 캐시 대상 파일을 변경하면 캐시 버전을 갱신하여 업데이트가 전달되도록 합니다.
- 배포 완료 여부는 GitHub Actions에서 확인합니다.

## 방문 분석

기존 GA4 속성을 사용합니다.

- FAQ·랜더마이저의 이벤트와 매개변수, 집계 기준 및 관리 화면 등록 항목은 [ANALYTICS.md](ANALYTICS.md)를 참고하세요.
- 시뮬레이터에는 페이지 방문 추적만 추가되어 있습니다. 진입 버튼 클릭, 원판 회전, 언어 변경용 맞춤 이벤트는 추가하지 않았습니다.
- 코드 반영과 실제 GA4 수신 확인은 별개이며, 수신 여부는 해당 속성에서 확인해야 합니다.

## 이미지 출처

태양계 원판과 태양 이미지의 원본은 Czech Games Edition의 [SETI Solar System Randomizer](https://seti-solarsystem.czechgames.com/)에서 제공하는 자료입니다. 이 사이트에서는 원본 그림을 유지하며 배경·외곽 그림자의 투명도를 정리한 이미지를 사용합니다.
